Compile LATEX without installing TeX.

One Docker image with the full TeX Live distribution. Mount your folder, name your .tex file, and get a PDF. The same build on your laptop, your coauthor's laptop and CI.

$ docker run --rm -v "$PWD":/mnt/src ghcr.io/soleo/latex example.tex

1Who it's for

Anyone who writes in LATEX but doesn't want a 7 GB TeX install managed by hand on every machine.

Researchers and students

Papers, theses and slides with BibLaTeX and biber. Every coauthor builds with the same TeX Live, so a package update on one laptop can't break the shared draft.

Developers and CI

Generate reports, docs and invoices in a pipeline. One docker run step, no TeX setup on the runner, and a non-zero exit code when the build fails.

People writing a CV

Modern CV templates need XeLaTeX and real fonts. Open Sans, Merriweather, Font Awesome and the rest of TeX Live's fonts load by name.

2Usage

  1. Get a Docker engine

    On macOS, Rancher Desktop is free. Choose the dockerd (moby) engine and turn Kubernetes off. On Linux, any Docker Engine works.

    brew install --cask rancher
export PATH="$HOME/.rd/bin:$PATH"   # add to ~/.zshrc
docker version

  2. Pull the image

    It is large (about 8 GB) because it carries all of TeX Live. You download it once.

    docker pull ghcr.io/soleo/latex
# or build it yourself
git clone https://github.com/soleo/docker-latex && cd docker-latex
docker build -t ghcr.io/soleo/latex .

  3. Compile

    Run it from the folder that holds your document. latexmk reruns the engine, BibTeX or biber until cross-references settle, then removes the aux files. The PDF lands next to the source.

    docker run --rm -v "$PWD":/mnt/src ghcr.io/soleo/latex paper.tex

  4. Keep a shortcut

    Add this to your ~/.zshrc or ~/.bashrc, then type docker-latex paper.tex.

    docker-latex() { docker run --rm -v "$PWD":/mnt/src ghcr.io/soleo/latex "$@"; }

3Engines

pdfLaTeX is the default. Set LATEX_ENGINE when your document needs Unicode input or system fonts through fontspec.

EngineSet withUse it for
pdfLaTeX(default)Most papers and journal templates
XeLaTeX-e LATEX_ENGINE=xelatexCVs, custom fonts, CJK text
LuaLaTeX-e LATEX_ENGINE=lualatexfontspec with Lua scripting, large documents

Build a CV with XeLaTeX

docker run --rm -v "$PWD":/mnt/src \
  -e LATEX_ENGINE=xelatex \
  ghcr.io/soleo/latex cv.tex

Run any tool directly

A command name as the first argument runs as-is.

docker run --rm -v "$PWD":/mnt/src ghcr.io/soleo/latex biber paper
docker run --rm ghcr.io/soleo/latex fc-list :family

4In GitHub Actions

Build the PDF on every push and keep it as a workflow artifact.

jobs:
  pdf:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Compile
        run: docker run --rm -v "$PWD":/mnt/src ghcr.io/soleo/latex paper.tex
      - uses: actions/upload-artifact@v4
        with:
          name: paper
          path: paper.pdf

6Before you compile someone else's project

latexmk runs any latexmkrc or .latexmkrc in the mounted folder, and that file is Perl code. The container runs as root and can write anywhere in the folder you mount. Only compile projects you trust.
